# AI Tools

Command-line tools for AI coding workflows and local log analysis.

| Project | Description | Documentation |
| --- | --- | --- |
| [Agent Sandbox](agent-sandbox/) | Runs Codex, Claude Code, opencode, or pi inside Docker with a separate Git worktree. | [Documentation](https://ernesto27.github.io/ai-tools/) |
| [Soft Factory](soft-factory/) | Uses Agent Sandbox to implement tasks, review changes, apply corrections, assess risk, and explain the results. Supports tasks from local files or Jira. | [Documentation](https://ernesto27.github.io/ai-tools/soft-factory/) |
| [Loglens](loglens/) | Analyzes local text and JSON Lines logs with filters and bounded-memory summaries. | [Documentation](loglens/README.md) |
