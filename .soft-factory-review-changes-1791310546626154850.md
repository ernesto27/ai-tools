## Behavior flow

```text
TCP listener on 0.0.0.0:8080
  -> bounded sync queue (64 accepted connections)
  -> one of 16 workers
  -> read headers/body (64 KiB header cap, 1 MiB body cap, 10 s deadline)
       -> no complete request / read error: close or log request failure
       -> request
            -> GET /health: 200 {"status":"ok"} (without todo-state lock)
            -> /todos: list or validate/create todo
            -> /todos/{id}: find then read/update/delete
                 -> bad input / missing route or id / full capacity: JSON error
                 -> successful operation: JSON todo/list/deleted result
  -> HTTP response with JSON content type, content length, and connection close
```

`main` binds all interfaces on port 8080, initializes shared state under `Arc<Mutex<_>>`, and starts 16 workers reading streams from a bounded synchronous channel. The receiver mutex is held only while receiving, then released before connection handling. The accept loop sends accepted streams into the 64-slot queue. `handle_connection` parses and dispatches a request, maps selected status codes, and writes JSON with content length and `Connection: close`. The health route consequently uses the required media type. Keep-alive and a general HTTP framework are not implemented.

#### Request reader and deadline (current lines 94–175)

`read_request` accumulates bytes through CRLF-CRLF, returns no request for oversized headers, parses method/path, then reads the declared `Content-Length` up to 1 MiB. `read_before_deadline` sets each socket timeout from the same 10-second deadline. Oversize bodies and timeouts become I/O errors; workers log those failures and close the connection without an HTTP error response.

Finding: a short body is accepted. On early EOF, the loop exits on `count == 0`, then constructs a request from the bytes already received without checking `bytes.len() == request_end`. A body containing a complete JSON object but fewer bytes than declared can still be routed as complete. Reject EOF before `request_end` and return a 400 response where possible.

Finding: malformed or duplicate `Content-Length` is not rejected. The code takes the first matching header, parses it with `.ok()`, and defaults to zero (lines 129–134); conflicting duplicate lengths are silently resolved as well. This makes framing differ from the client's declaration. Require a single valid length and reject invalid/conflicting framing.

+fn read_request(stream: &mut TcpStream) -> std::io::Result<Option<Request>> {
+    let deadline = Instant::now() + READ_TIMEOUT;
+    let mut bytes = Vec::new();
+    let mut chunk = [0; 4096];
+    let header_end;
+    loop {
+        let count = read_before_deadline(stream, &mut chunk, deadline)?;
+        if count == 0 {
+            return Ok(None);
+        }
+        bytes.extend_from_slice(&chunk[..count]);
+        if let Some(index) = find_bytes(&bytes, b"\r\n\r\n") {
+            header_end = index + 4;
+            if header_end > MAX_HEADER_BYTES {
+                return Ok(None);
+            }
+            break;
+        }
+        if bytes.len() > MAX_HEADER_BYTES {
+            return Ok(None);
+        }
+    }
+
+    let headers = String::from_utf8_lossy(&bytes[..header_end]);
+    let first_line = headers.lines().next().unwrap_or_default();
+    let mut request_parts = first_line.split_whitespace();
+    let Some(method) = request_parts.next() else {
+        return Ok(None);
+    };
+    let Some(path) = request_parts.next() else {
+        return Ok(None);
+    };
+    let method = method.to_owned();
+    let path = path.to_owned();
+
+    let content_length = headers
+        .split("\r\n")
+        .filter_map(|line| line.split_once(':'))
+        .find(|(name, _)| name.eq_ignore_ascii_case("content-length"))
+        .and_then(|(_, value)| value.trim().parse::<usize>().ok())
+        .unwrap_or(0);
+    if content_length > MAX_BODY_BYTES {
+        return Err(std::io::Error::new(
+            std::io::ErrorKind::InvalidData,
+            "request body exceeds configured limit",
+        ));
+    }
+    let request_end = header_end.checked_add(content_length).ok_or_else(|| {
+        std::io::Error::new(std::io::ErrorKind::InvalidData, "request length overflow")
+    })?;
+    while bytes.len() < request_end {
+        let count = read_before_deadline(stream, &mut chunk, deadline)?;
+        if count == 0 {
+            break;
+        }
+        let remaining = request_end - bytes.len();
+        if count > remaining {
+            bytes.extend_from_slice(&chunk[..remaining]);
+            break;
+        }
+        bytes.extend_from_slice(&chunk[..count]);
+    }
+    let body_end = bytes.len().min(request_end);
+    let body = String::from_utf8_lossy(&bytes[header_end..body_end]).into_owned();
+    Ok(Some(Request { method, path, body }))
+}
+
+fn read_before_deadline(
+    stream: &mut TcpStream,
+    buffer: &mut [u8],
+    deadline: Instant,
+) -> std::io::Result<usize> {
+    let remaining = deadline.saturating_duration_since(Instant::now());
+    if remaining.is_zero() {
+        return Err(std::io::Error::new(
+            std::io::ErrorKind::TimedOut,
+            "request read deadline exceeded",
+        ));
+    }
+    stream.set_read_timeout(Some(remaining))?;
+    stream.read(buffer)
+}

#### Root-object traversal (current lines 324–375)

`root_json_field` requires a root object, walks each key/value structurally, and captures the first matching member. This prevents a nested `title` or text inside a string from being mistaken for a root member. It requires the object to consume all input and rejects a trailing comma. Duplicate keys are accepted with the first occurrence winning. The comment at 324–326 explains the nested-key protection.

+fn root_json_field<'a>(input: &'a str, field: &str) -> Option<&'a str> {
+    let bytes = input.as_bytes();

+    if *bytes.get(index)? != b'{' {
+        return None;
+    }
+    index += 1;

+    let mut after_comma = false;
+

+        if *bytes.get(index)? == b'}' {
+            if after_comma {
+                return None;
+            }
+            index = skip_json_whitespace(bytes, index + 1);

+            return None;
