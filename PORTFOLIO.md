# Alex Rivera — retro portfolio

A responsive concept portfolio built with native HTML, CSS, and JavaScript. No package installation or build step is needed.

From the repository root, run:

```sh
python3 -m http.server 8080
```

Open http://localhost:8080. Project filters, keyboard-accessible detail dialogs, mobile navigation, email copying, and an optional original synth arpeggio are implemented in the browser.

The identity, projects, and email address are illustrative. Replace them in `index.html` and `script.js` before using this as a personal portfolio. Typography uses Google Fonts when available and falls back to local system fonts.
